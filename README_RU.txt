# Piggy World — Godot 4 Android project

## Быстрая сборка APK через GitHub Actions (можно с телефона)

1. Создайте на GitHub новый публичный или приватный репозиторий с именем `PiggyWorld`.
2. Распакуйте этот ZIP на телефоне.
3. Загрузите ВСЕ файлы и папки проекта в корень репозитория (в том числе `.github/workflows/android-apk.yml`).
   Важно: при загрузке через сайт GitHub проверьте, что папка `.github` и файл workflow тоже попали в репозиторий.
4. Откройте вкладку **Actions** репозитория.
5. Выберите **Build Piggy World APK** и нажмите **Run workflow** (если сборка не запустилась автоматически после загрузки).
6. Дождитесь зелёной галочки у завершённого запуска.
7. Откройте запуск workflow, прокрутите до **Artifacts** и скачайте `PiggyWorld-Android-APK`.
8. Распакуйте скачанный архив и получите `PiggyWorld.apk`.

## Локальный запуск
Откройте `project.godot` в Godot 4.4 или совместимой версии и нажмите Run.

## Управление
- ПК: WASD — движение, пробел — прыжок.
- Телефон: левая половина экрана — виртуальное направление; правая — прыжок.
- Соберите 24 монеты.

## Примечание
Это исходный проект и конфигурация облачной сборки, а не готовый APK.
GitHub Actions собирает APK автоматически; для публикации в Google Play потребуется отдельная настройка подписи и аккаунта разработчика.
