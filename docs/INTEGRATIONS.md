# External references and integration notes

- [Seasons Gone](https://github.com/elliotfontaine/untitled-farming-sim) (MIT): reviewed its soil nutrient and crop-family rotation concepts. PiggyWorld's soil rules are a separate implementation adapted to this game's crop/day model; no source code was copied.
- [Plant and Prosper](https://github.com/nadia-nh/rc-godot-farm-rpg) (GPL-3.0 project): reviewed its farming architecture. Only the individual crop sprites and potato seed icon documented in ASSETS.md were imported; its game code was not copied.
- [Tiddybub/2d-assets](https://github.com/Tiddybub/2d-assets): reviewed as a CC0 asset discovery index. No files from this catalog are currently bundled in PiggyWorld.

The potato growth sprites and seed icon are identified as CC0 in the Plant and Prosper README. See docs/ASSETS.md for details.
